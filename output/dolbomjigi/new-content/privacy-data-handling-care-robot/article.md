<AnswerBlock>
돌봄로봇은 부모님 댁을 무단 촬영하거나 일상 대화를 도청하지 않습니다. 국가 공인 보안 가이드라인에 따라 카메라 영상은 로봇 내부에서 실시간 처리된 후 즉시 삭제되며, 음성 데이터는 주민번호나 금융 정보를 제외한 익명 코드 형태로 종단간 암호화(E2EE)되어 전송됩니다. 물리적 렌즈 가리개와 마이크 차단 스위치로 완벽한 사생활 통제가 가능합니다.
</AnswerBlock>

"로봇에 카메라랑 마이크가 달려 있다는데, 내가 방 안에서 속옷 차림으로 돌아다니는 모습이 밖으로 다 새어 나가는 것 아니냐? 나를 하루 종일 감시하는 것 같아서 찝찝해 죽겠다!"

부모님 댁에 돌봄로봇을 설치해 드리려 할 때 가장 거세게 부딪히는 심리적 장벽이 바로 **'사생활 침해와 감시 공포'**입니다. 평생 본인만의 안락한 영역이었던 안방이나 거실에 낯선 기계가 들어와 눈을 깜빡이고 귀를 쫑긋 세우고 있으니, 누군가 뒤에서 나를 훔쳐보고 도청한다는 오해를 사기 십상입니다.

실제로 시중의 저가형 중국산 홈캠이나 해킹에 취약한 IP 카메라는 사생활 유출 사고로 뉴스에 오르내려 불안감을 증폭시키기도 했습니다.

하지만 정부와 지자체가 공인하여 보급하는 **정규 시니어 돌봄로봇은 일반 감시 카메라와 설계 목적과 보안 프로토콜부터 완전히 다릅니다.** 부모님의 걱정을 덜어드리는 3중 보안 기술과 개인정보 보호 체계를 알기 쉽게 짚어드립니다.

## 1. 일반 가정용 홈캠(CCTV) vs 시니어 돌봄로봇 보안 비교

일반적인 감시 카메라와 돌봄로봇의 데이터 취급 방식은 근본적인 차이가 있습니다.

| 비교 항목 | 일반 가정용 홈캠 (IP 카메라) | 표준 시니어 돌봄로봇 |
| :--- | :--- | :--- |
| **영상 저장 방식** | 클라우드 서버나 SD 카드에 24시간 풀 영상 저장 | 실시간 움직임 판별 후 즉시 폐기 (서버 저장 일절 없음) |
| **촬영 데이터 형태** | 얼굴과 옷차림이 그대로 노출되는 고화질 컬러 영상 | 비카메라 레이더 및 관절 스켈레톤(뼈대) 좌표 데이터 변환 |
| **음성 데이터 처리** | 통화 녹음 파일이 서버에 장기 보관 | 음성 명령 수행 즉시 텍스트 로그만 남기고 원본 음성 삭제 |
| **통신 보안 규격** | 기본 비밀번호 취약, 외부 해킹에 노출 위험 | 국가 공인 IoT 보안 인증 및 금융권 수준 256비트 종단간 암호화 |
| **물리적 차단 장치** | 렌즈를 가리려면 테이프를 붙여야 함 | 전용 물리적 슬라이딩 셔터 및 마이크 음소거 하드웨어 스위치 내장 |

## 2. 부모님 사생활을 지키는 3중 기술 방파제

돌봄로봇은 부모님의 존엄성과 프라이버시를 최우선으로 보호하기 위해 3가지 강력한 안전장치를 탑재하고 있습니다.

```
[1단계: 온디바이스 AI (On-Device Processing)]
외부 서버로 영상을 전송하지 않고, 로봇 내부 칩셋에서 "사람이 서 있는지, 누워 있는지"만 판별
분석 즉시 원본 영상 프레임 메모리에서 영구 소거

[2단계: 데이터 비식별화 및 금융권 암호화 (E2EE)]
음성 일기 및 건강 데이터는 "홍길동 어르신" 이름 대신 난수화된 식별 코드(User-UUID)로 치환
전송되는 모든 패킷은 AES-256 비트 암호화 적용으로 해킹 원천 차단

[3단계: 물리적 하드웨어 킬 스위치 (Physical Shutter)]
소프트웨어 오류나 해킹 걱정마저 지워주는 물리적 덮개:
렌즈 앞을 손으로 밀어 닫으면 광학적으로 시야 100% 차단
```

### 1단계: 서버로 영상을 보내지 않는 '온디바이스 엣지 AI'
- 최신 돌봄로봇은 카메라 영상을 통신망을 통해 외부 관제 센터나 서버로 업로드하지 않습니다.
- 로봇 본체 안의 인공지능 칩이 현장에서 직접 '낙상 여부'나 '얼굴 인식'을 판별한 뒤, 결과값인 신호(예: "낙상 발생")만 보낼 뿐 실제 영상은 기기 밖으로 단 1초도 유출되지 않습니다.

### 2단계: 주민번호와 계좌번호는 절대 묻지 않는 데이터 정책
- 돌봄로봇은 금융 거래나 인증을 수행하지 않습니다. 어르신이 대화 도중 계좌번호나 비밀번호를 말씀하시더라도 개인정보 필터링 시스템이 이를 감지하여 기록하지 않고 즉시 마스킹 처리합니다.

### 3단계: 손으로 직접 닫는 아날로그 프라이버시 셔터
- 기계에 대한 불신을 해소하는 가장 좋은 방법은 눈에 보이는 물리적 차단입니다.
- 옷을 갈아입거나 주무실 때 손가락으로 렌즈 커버를 닫아두면 카메라가 물리적으로 완벽히 가려져 어떠한 시각 정보도 입력되지 않습니다.

## 3. 부모님께 안심을 드리는 설명 화법 3가지

가족이 부모님께 기기를 권유할 때 오해를 풀 수 있는 다정한 대화 요령입니다.

1. **"카메라로 엄마를 감시하는 게 아니라, 손주가 인사하려고 화면이 달린 거예요"**:
   - 감시 기계가 아닌 '자녀와 얼굴 보며 통화하는 전용 화면'이라는 점을 먼저 강조하세요.
2. **"영상은 녹화되지 않고 방송국처럼 흘러가서 사라져요"**:
   - 집안 모습이 어딘가에 녹화되어 남는 것이 아니라는 점을 분명히 설명해 드립니다.
3. **"찝찝할 땐 이 뚜껑을 손으로 닫아두시면 돼요"**:
   - 부모님 스스로 기기를 통제할 수 있는 주도권(물리적 셔터)이 본인에게 있음을 알려드리면 거부감이 사라집니다.

## 자주 묻는 질문 (FAQ)

### Q1. 해커가 로봇을 해킹해서 부모님 집안을 들여다볼 수 있나요?
정부 표준 보안 인증을 획득한 돌봄로봇은 외부 인터넷망과 단절된 전용 폐쇄망(VPN) 또는 금융권 수준의 TLS 암호화 터널을 사용합니다. 외부에서 무단 접속을 시도하면 시스템이 즉시 포트를 차단하고 경보를 울리므로 일반 저가형 IP 카메라와 같은 해킹 위험이 전혀 없습니다.

### Q2. 복지관 사회복지사나 구청 공무원이 부모님 방 안을 실시간으로 볼 수 있나요?
절대 볼 수 없습니다. 관제 센터 화면에는 어르신의 영상이 뜨지 않으며, "08:30 식사 완료", "14:00 활동 보통", "온도 24℃" 같은 상태 텍스트와 센서 통계 데이터만 숫자로 표시됩니다. 공무원이나 복지사도 어르신의 실내 모습을 시각적으로 엿볼 수 없습니다.

### Q3. 로봇과 나눈 다정한 대화 내용이 인공지능 학습용으로 공개되나요?
아닙니다. 개인정보보호법에 따라 사용자의 사전 동의 없는 음성 데이터의 외부 공개 및 상업적 재활용은 엄격히 금지됩니다. 일상 대화는 어르신 맞춤형 피드백을 생성한 직후 비식별 처리되며 특정 개인을 식별할 수 있는 형태로 보관되지 않습니다.

### Q4. 기기를 해지하거나 반납할 때 그동안의 데이터는 어떻게 되나요?
해지 시 본체 내부에 저장된 모든 사용자 데이터는 공장 초기화(Factory Reset)를 거쳐 영구 삭제됩니다. 중앙 서버에 남아 있는 통계 로그 역시 개인정보 파기 절차에 따라 30일 이내에 복구 불가능한 형태로 영구 파쇄 처리됩니다.
